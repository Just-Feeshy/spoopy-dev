Introduction
------------

Spoopy Environment (or Spoopy Envi. for short) is a surface-level, lightweight framework designed to simplify game development.

Spoopy Environment is planned to be highly portable, and primarily written in C11, using SDL3 and Kore V2. It is currently only supported for macOS for the ARM64 processor.
